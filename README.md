# Лексика

Приложение для изучения английского с личным словарём, карточками, диктантами и аккаунтами.

Render: Web Service, Docker, Free. Neon: Free PostgreSQL. Секрет DATABASE_URL задаётся только в Render Environment. Адрес задаётся Render автоматически.

Piper TTS 1.8.0: GPL-3.0, https://github.com/OHF-Voice/piper1-gpl. Модели Ruslan и Lessac загружаются из официального репозитория piper-voices при сборке. Ruslan: CC BY-NC-SA 4.0.

Личные сохранения и данные аккаунтов не включены. Для переноса словаря экспортируйте его из локальной версии и импортируйте после входа на новом сайте.
